# Capítulo 4: Apresentação

Este documento serve como guião para a apresentação do projeto **ActiveFrame** na disciplina de Tecnologias de Internet. O objetivo é resumir os pilares tecnológicos e a proposta de valor da aplicação para a defesa perante o docente.

## 1. Visão Geral e Proposta de Valor
O **ActiveFrame** diferencia-se por não se limitar ao registo quantitativo (calorias, repetições, macros). O foco central é a **monitorização visual da evolução física**, utilizando o diário fotográfico como o principal motor de motivação para o utilizador. A aplicação centraliza a gestão de treinos e alimentação numa interface intuitiva e responsiva.

## 2. Pilares Tecnológicos
A apresentação destaca a solidez da arquitetura desenvolvida:
* **Estruturação de Dados:** O sistema utiliza **XML**, validado por **XSD**, garantindo que a informação seja estruturada de forma rigorosa e consistente.
* **Lógica Dinâmica:** O **JavaScript** é utilizado para processar os dados em tempo real, gerir a autenticação de utilizadores e manipular a interação entre o conteúdo XML e o interface HTML.
* **Persistência:** A utilização de **LocalStorage** permite uma experiência personalizada que persiste localmente no navegador, sem a necessidade de um servidor de base de dados complexo para este âmbito académico.

## 3. Experiência de Utilizador (UX/UI)
O foco na usabilidade é transversal a toda a apresentação:
* **Navegação Intuitiva:** O fluxo de utilizador (Sitemap) foi desenhado para separar a zona pública da zona privada, protegida por sessão.
* **Ajuda ao Preenchimento:** Implementação de campos orientados com *placeholders* e validações híbridas (XSD no backend/estrutural e JS no frontend/dinâmico), prevenindo erros de introdução de dados.
* **Responsividade:** O design é adaptativo, garantindo uma utilização funcional em diferentes dispositivos.

## 4. Conformidade e Resultados
A apresentação termina reforçando o cumprimento de todos os requisitos do enunciado, com especial destaque para a implementação de HTML semântico, o uso de CSS externo (sem *inline*), a integração multimédia (vídeo com áudio) e a correta automatização do *deploy* via Netlify, que atesta o profissionalismo do processo de entrega do projeto.
