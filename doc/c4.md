# Capítulo 4: Apresentação

Este documento resume os pilares do projeto **ActiveFrame** para efeitos de defesa oral.

## 1. Proposta de Valor
O **ActiveFrame** é uma plataforma de gestão de saúde que alia métricas quantitativas (treinos e dieta) ao **registo visual (fotográfico)**, promovendo a motivação e o acompanhamento tangível da evolução física.

## 2. Solução Técnica
* **Dados:** Estruturados em **XML** e validados por **XSD** para garantir consistência.
* **Lógica:** Manipulação dinâmica via **JavaScript** (autenticação e processamento).
* **Persistência:** Utilização de **LocalStorage** para armazenamento local no browser.
* **Deploy:** Automatizado via **Netlify** (repositório GitHub).

## 3. Experiência de Utilizador (UX/UI)
* **Navegação:** Estrutura clara entre zonas públicas e privadas (protegidas).
* **Usabilidade:** Formulários com validação híbrida (XSD + JS) e *placeholders* orientadores.
* **Responsividade:** Design adaptativo para múltiplos dispositivos.

## 4. Conformidade (Requisitos)
O projeto cumpre integralmente os requisitos da unidade curricular:
* HTML semântico e CSS externo (sem *inline*).
* Integração multimédia (vídeo com áudio).
* Estrutura organizada (tabelas, listas, formulários).
